# Smart Expense Tracker

A Java console application for managing and tracking personal expenses.

## 📌 About the Project

Smart Expense Tracker is a command-line Java application that allows users to record, view, search, and analyze their personal expenses.

The project was developed to practice core Java programming concepts, object-oriented programming, collections, input validation, and clean code organization.

## ✨ Features

* Add new expenses
* View all recorded expenses
* Search expenses
* Calculate total expenses
* Organize expenses by category
* Validate user input
* Support for multiple expense categories
* User-friendly console menu

## 📂 Project Structure

```text
SmartExpenseTracker/
│
├── Main.java
├── Expense.java
├── ExpenseManager.java
├── Category.java
├── InputValidator.java
├── .gitignore
└── README.md
```

### Main.java

Contains the main application flow and console menu.

### Expense.java

Represents an individual expense and stores information such as amount, category, description, and date.

### ExpenseManager.java

Handles the collection of expenses and provides operations for managing and analyzing them.

### Category.java

Defines the available expense categories using a Java `enum`.

### InputValidator.java

Handles validation of user input to make the application more reliable and prevent invalid entries.

## ▶️ How to Run

### Requirements

* Java JDK 17 or later
* Git (optional, for version control)

### Run the application

Clone the repository:

```bash
git clone https://github.com/Moysiss/SmartExpenseTracker.git
```

Navigate to the project directory:

```bash
cd SmartExpenseTracker
```

Compile the Java files:

```bash
javac *.java
```

Run the application:

```bash
java Main
```
